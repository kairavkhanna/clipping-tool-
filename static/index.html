      Publish to YouTube

      Connected as .

      Uploads a finished clip straight to your own channel. Needs a free Client ID and Client Secret from your own Google Cloud project — see YouTube_SETUP.md in the Clipper folder for the one-time, 5-minute setup. Nothing is sent anywhere except Google.

      Add a video to start clipping

      Upload a file or paste a YouTube link on the left. Then set a start and an end on the timeline and create your clip.

      I sets the start, O sets the end, P plays the selection, Space plays or pauses. Focus a handle and use the arrow keys to nudge it by 0.1 seconds (hold Shift for 1 second).

      Find the best moments

      AI reads what is said in this video and suggests clips that make sense on their own. The first run transcribes the video, which can take a while on long videos.

        Summary video

        Turn a long video into a short recap with captions, in landscape 16:9. Explained: the AI writes the story and a narrator tells it over the video's own pictures. Best scenes: keeps the original sound and joins the most important parts. The first run transcribes the whole video, which is slow for a 2 hour video, but it is saved for next time.         Make a video from a script

        Write what should be said. Clipper adds a voiceover, a background and captions, in vertical 9:16.

        Need a script? Let AI write one

        Voices come from a free online service, so this needs an internet connection. For a Hindi script pick a Hindi voice. To use your own footage as the background, add it to the library first.

        Make lots of videos at once

        Queue as many as you like. Clipper works through them one by one, so you can leave it running. Everything lands in Your clips, and each batch can be downloaded as one zip. If something fails it is retried, and a failure never stops the rest.

        Voiceover videos from scripts or topics

        Need ideas? Let AI list topics

        Separate scripts with a blank line. For the free voice service, keep a short pause between videos (Clipper does this for you). Use a Hindi voice for Hindi text.
